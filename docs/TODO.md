## Current App State

- LFM Orbit is a demo-ready, local-first mission-control prototype, not an unattended production deployment.
- The hackathon runtime is built around DPhi Space SimSat (`simsat_sentinel`). Direct Sentinel Hub, NASA, and GEE-style providers are optional development/replay support and must not become required showcase dependencies.
- SimSat Mapbox routing only requires a non-empty `MAPBOX_ACCESS_TOKEN` inside Orbit, which matches the local hackathon wrapper behavior. Real upstream Mapbox imagery still requires a valid token, and empty SimSat image payloads are rejected before scoring.
- Mission Control can run realtime provider/API scans, replay cached real API imagery, monitor previews, optional visual evidence helper calls, timelapse generation, and dataset export paths.
- Runtime evidence surfaces expose three separate fields: `runtime_truth_mode` (`realtime`, `replay`, `fallback`), `imagery_origin` (`sentinelhub`, `simsat`, `nasa_gibs`, `gee`, `cached_api`, etc.), and `scoring_basis` (`multispectral_bands`, `proxy_bands`, `visual_only`, `fallback_none`).

- The README now embeds a GitHub-safe Greenland Sentinel-2 L2A timelapse GIF generated from cached replay media; the companion WebM is linked for higher-quality playback.
- Fallback means degraded runtime behavior: provider error, quality gate, heuristic proxy, or visual-helper compatibility fallback. Fallback paths must not masquerade as realtime imagery or high-confidence model output.
- Fast Replay can load curated replay packs and structurally valid cached API WebMs, then rescan saved metadata through the current runtime/model stack.
- Ground Agent chat now uses proposal cards for mutating local actions, so replay loads/rescans, mission packs, and SAT/GND link changes show provenance and expected state impact before the operator confirms; backend action errors stay visible instead of being marked confirmed, and post-action UI refresh failures are reported separately from successful action execution.

## Edge Cases To Keep Covered

- Replayed cached API imagery must be labeled as `runtime_truth_mode=replay`, not as a run-context or fallback label.
- Realtime provider paths must include the provider/API family through `imagery_origin`; avoid vague standalone "live" labels in evidence surfaces.
- Fallback paths must carry fallback provenance and must not produce high-confidence positive alerts from provider errors, quality-gate failures, or heuristic-only visual-helper output.
- Empty or malformed provider credentials must report unavailable status without switching to external calls unexpectedly.
- Settings credential writes must trim input and reject blanks without replacing a local secret file.
- Blank visual-evidence prompts or questions must fail validation before optional fallback/model work starts.
- Object target labels must stay within civilian evidence scope. Denied labels such as `person`, `people`, `individual`, `soldier`, `weapon`, `target`, `strike`, `manatee`, and `population`, including common plurals, must continue to be rejected before custom packs or mission targets are saved.
- Custom target packs must write only under `runtime-data/object-targets/custom_target_packs.json`; versioned default pack JSON must remain read-only at runtime.
- Mission target edits must go through the backend registry normalization path so frontend chips, Ground Agent proposals, and batch grounding do not fork object-label logic.
- Runtime resets should preserve operator mission intent in the local mission archive unless callers explicitly set `archive_missions=false` for isolated tests.
- Dataset exports must use stored mission/replay/cache metadata before reaching for external providers, preserving API-cost discipline and future model-training value.
- Batch grounding must keep disabled targets skipped and must normalize all returned boxes to `unit_xyxy` before map rendering or proof packaging.
- Batch grounding must discard degenerate boxes after normalization/clamping so off-frame model output cannot inflate object counts.
- API list surfaces should return stable repo-relative artifact paths, not user-specific absolute filesystem paths.
- SimSat Mapbox may be configured with a placeholder token for local route tests, but Mapbox-backed imagery must not be scored unless SimSat returns non-empty image bytes.
- Glowing CV boxes and tooltips must remain candidate evidence when runtime mode is fallback, and must not imply confirmed detection without model/replay/operator support.
- Garbage, plastic, and marine-debris prompts must stay candidate-only unless a future `marine_debris` lane produces multispectral evidence and still passes operator review; never convert location navigation directly into a debris scan without a second confirmation.
- Algae, cyanobacteria, chlorophyll, red tide, and HAB prompts must stay candidate-only unless a future `harmful_algal_bloom` lane produces multispectral water-quality evidence and still passes operator review; never claim toxicity, species, microcystin, or Karenia brevis without NOAA/FDEP or field confirmation.
- Confirmed Ground Agent missions must interrupt any boot/default scan pass quickly enough that a new user sees the selected area scan, complete, and produce reviewable result chips without waiting for an unrelated region cycle.
- Map scan/sweep animation should render only during an active live mission scan. Stopped missions, replay contexts, and camera-only navigation should show paused/idle state instead of a moving scanner footprint.
- Critical-minerals outputs must stay region-level unless externally validated: do not claim illegal mining, pollution confirmation, exact production, or resource output from imagery alone.
- Coastal debris/slick outputs must stay candidate evidence and should be near visible coastal/river/port/storm context; do not claim Great Pacific Garbage Patch mass growth from optical satellite imagery.
- README story plates must keep `box_source=visual_story_fixture` visible unless they are generated from a real model-backed detection path; object-scale roof/shelter screenshots should use appropriate context imagery instead of pretending Sentinel-2 can resolve individual roofs.
- Newly generated public story plates must be treated as candidates until visual review passes. Public plate metadata must include `visual_audit_status=approved`, and public labels should say area/group/zone/sample/candidate unless the underlying box is truly object-scale.
- Targeted visual-story rebuilds must not truncate `visual_story_manifest.json`; selected stories should merge back into the existing ordered manifest.
- Roof/building story plates must say when boxes are samples; do not imply every visible roof was detected unless an exhaustive model-backed count is actually available.
- 3D context views must never be labeled as timeline frames unless matching dated 3D datasets exist; they must keep context timestamp, source, and attribution visible.
- 3D overlays must reuse the active 2D bbox/object-evidence geometry instead of redefining separate polygons that can drift.
- Invalid or missing bbox geometry must keep the 3D view unavailable instead of creating NaN camera/geometry state.
- MapLibre 3D context code and any future 3D Tiles dependencies must stay lazy-loaded so the default 2D timeline map remains the cold-start path.
- Basemap render/tile/WebGL failures must stay operator-visible and must not alter mission scoring or evidence provenance.
- Image-trained handoff artifacts must not be described as direct image-conditioned Orbit inference unless the runtime passes image pixels into an adapter and status reports `image_conditioned_runtime_enabled=true`.
- `/api/inference/image` should stay structured and provenance-rich when unavailable so frontend callers can fail softly instead of implying image runtime success.
- Cloudy, stale, missing, RGB-only, or non-numeric spectral inputs must abstain rather than fabricate spectral indices.
- Quality-gated cloud/no-data failures must not emit `suspected_canopy_loss`, even when raw band deltas look large.
- Cached replay/training frames must carry frame-quality metadata and reject cloudy frames before WebM creation.
